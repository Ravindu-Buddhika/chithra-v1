# CHITHRA AI 🤖

CHITHRA (Creative Human-Interface Task-Handling Robot Assistant) is a personal AI assistant built with Python. This project follows a **Modular Architecture**, separating the "Brain" (Logic/AI) from the "Body" (Voice/Automation).

## 🚀 Features (Work in Progress)
- **Modular Design**: Separate files for Voice, Brain, and Main logic for better scalability.
- **Natural Voice**: Uses Windows SAPI (Speech API) for clear and reliable voice output.
- **Intent Recognition**: Designed to integrate with Gemini AI for intelligent conversations.

## 🏗️ Project Structure
- `main.py`: The entry point of the assistant.
- `voice.py`: Handles text-to-speech functionality.
- `brain.py`: (Coming Soon) Integration with LLM for intelligent responses.

## 🛠️ Tech Stack
- **Language**: Python 3.x
- **Libraries**: `pywin32` (for SAPI voice)
